模块 16 HLS 内核 lm_head_argmax

module16_lm_head_hls/src/lm_head_kernel.cpp 实现的单个 IP 完成整条收尾链路： FP16 hidden × FP16 weight → FP32 累加 → FP16 raw logits → repetition penalty → greedy argmax → token。 当前版本是功能基线，点积内层为单累加器串行实现（II = 8），尚未做多 PE 优化。
