9. 教程与参考资源

除了主线工程（golden trace → Python 参考 → HLS → 上板），仓库里还收集了一批教程、前作参考、外部模板和关键文档。本章按用途把它们整理出来，方便查阅。这些资料大多是「只读」的参考区，不参与主线构建。

9.1 零基础教程：module16_fpga_tutorial/

module16_fpga_tutorial/ 目录下藏着一份完整的零基础导览教程——真正的内容是其中的 index.html（约 33KB 的单文件网页）：

《从 CPU 到 FPGA：模块 16 零基础导览》

完全离线、零依赖的单文件 HTML，双击即可在浏览器中阅读，不需要任何服务器或构建步骤。

教程包含的 8 个 section

  1. 全景 —— 模块 16（LM Head）在整个推理流程中的位置。
  2. 计算公式 —— lm_head 矩阵乘、repetition penalty、argmax 的数学定义。
  3. HLS / RTL / AXI 基础概念 —— 面向零基础读者的概念入门。
  4. 任务 —— 本章工程要完成的目标拆解。
  5. 分层验证 —— csim → cosim → 板级回环的逐级验证方法。
  6. TCP 网口协议 —— LMH1 帧协议的通俗讲解。
  7. 上板流程 —— 从 Vivado 工程到 AXU9EGB 点亮的完整步骤。
  8. FAQ —— 常见问题汇总。

教程引用了仓库内的实测结果，数据与本文档站其他章节一致：

验证层级实测结果
HLS C 仿真（csim）8/8 PASS
4×4 RTL 协同仿真（cosim）1/1 PASS
TCP trace 回环8/8 PASS
串行核性能约 3.299 s/token
module16_fpga_tutorial/ 目录里的 app/、worker/、db/、drizzle/ 等子目录是建站工具留下的 vinext 模板脚手架（Next.js 16 + React 19 + Cloudflare Workers），只渲染骨架占位页，与 FPGA 教程没有代码耦合、尚未被定制，阅读教程时直接忽略即可。

9.2 RMSNorm 前作参考：ref/（只读资料区）

ref/ 是本工程的「前作」——RMSNorm 算子 FPGA 化的完整资料。模块 16 的 TCP 服务器设计、PS 配置都参考或对齐了它。

ref/RMS/ —— RMSNorm 软件与测试向量

文件说明
Vitis_IDE/lwip_rmsnorm_raw_server.cPS 端裸机 lwIP TCP 服务器：协议 OFRMSRQ1/OFRMSRP1，端口 50052，36 行 × 896 维 BF16 输入，调用 XRmsnorm_layer0_prefill HLS IP——是模块 16 TCP 服务器设计的前作参考。
rmsnorm_fpga_backend.pyPython 后端，支持三种模式：本地 BF16 仿真、ZIP Ethernet RPC、AXU9EGB raw Ethernet。
测试向量生成脚本 + rmsnorm_test_vectors.hRMSNorm 测试向量的生成与 C 头文件形式。

ref/rmsnorm_axu9eg/ —— 完整 Vivado 工程

包含 .xpr 工程文件与 system_wrapper_wrapper.xsa，是 AXU9EGB 板上 RMSNorm IP 集成的硬件工程参考。realFpga 的 PS 配置即以此对齐——1111 项 PSU 参数中 1110 项一致。

ref/xemacpsif_physpeed.c —— lwIP PHY 速度协商源码

Xilinx lwIP 移植层的官方源码（PHY 速度协商部分），调试板载网口时的参考。其中的通用 PHY 识别补丁已被打入 realFpga 的 BSP。

ref/ 下的两个 .zip（RMS.zip、rmsnorm_axu9eg.zip）只是上述内容的压缩备份。

9.3 外部参考：tmp/（只读）
