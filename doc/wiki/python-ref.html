Python 参考实现

qwen25_0p5b_python_reference/ 提供三层次参考：可复现的 trace 导出（generate 路径）、 贴近 FPGA runtime 的显式 prefill/decode、以及不依赖 transformers 的纯模块级数学实现。 它们的共同产物就是 golden trace 与上板 fixture。
