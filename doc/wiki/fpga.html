上板部署 realFpga/

目标板卡 ALINX AXU9EGB（XCZU9EG-2FFVB1156I），工具链 Vivado / Vitis HLS / Vitis 2021.1。 第一版采用同事 RMSNorm 工程已验证过的路线：A53 standalone + lwIP raw TCP， PL 侧只放一个 lm_head_argmax IP，PL 时钟先跑 100 MHz。

Cache 规则：CPU 写入后必须 Xil_DCacheFlushRange()（否则 PL 读到旧值）， PL 写完 logits 后必须 Xil_DCacheInvalidateRange()（否则 CPU 读到旧值）。 权重按 1 MiB 分块，每块写完立即 flush，避免最后一次 flush 260 MiB 造成长阻塞。

Vivado Block Design 结构与复位拓扑

踩过的坑（log 049 / 051 / 052 / 053）：首次 4×4 上板在 PL 控制访问处锁死， 根因是 AXI 复位拓扑错误导致 IP 处于永久复位。逐级修复后， realFpga/vitis/probe_jtag.tcl、inspect_ps_pl_state.tcl、recover_ps_tap.tcl 成为上板预检的固定动作。任何 BD 改动后都应先确认复位释放，再谈功能。
