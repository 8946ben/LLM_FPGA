# M14 · lm_head v3 模块交付

本文件夹为张本负责的 lm_head v3（200 MHz）独立模块交付版，版本 `M14_V3_20261019_r1`，
供汇总负责人喻燕萍接收。包含源码、完整可综合 IP、PS 驱动、机器接口表、
资源/时序报告、完整 BF16 资产和真实板测证据。

本次同板各完成55项100/200 MHz验收。v3 的8步生产模式与8步完整 FP32 logits
均与黄金结果严格一致，4项错误路径、受控错误 golden、30次独立计时和1000次连续调用通过。
IP median/P95 为117.751805/117.751890 ms；A53 wall median 为117.767348 ms。
相对 v2 的224.868020 ms，速度为1.90968倍。272269312-byte BF16 权重通过 TCP
传输与逐块/全 DDR CRC 耗时8.3686665秒，另有主机SHA256与JTAG sentinel门槛。

5 ns 完整单模块布局布线通过：WNS +0.943 ns、WHS +0.010 ns、WPWS +1.000 ns；
LUT23148、FF40194、BRAM tile22、DSP59。DRC 0 Error/0 Critical Warning，普通警告保留。

v3 是发布名称，ABI仍为2，顶层符号仍为lm_head_v2，IP版本2.1，build_config=0x20c08011。
交付中的镜像和计算源码与本次实测版本按SHA256绑定。详细范围与状态见模块README、
module_manifest.json和interface/interface_contract.json；未把独立模块结果扩展为整模型性能。

接收后先核对ZIP SHA256，解压后在包根目录执行
`python -B module_14_lm_head_v3/scripts/run_tests.py`。默认大权重通过网口加载。
