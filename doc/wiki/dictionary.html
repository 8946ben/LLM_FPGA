术语词典：JTAG 调试目标

记录在 AXU9EGB / Zynq UltraScale+ MPSoC 调试时遇到的 JTAG 与处理系统术语。

先看它们的关系

术语

术语是什么在这块板上的作用
XSCT
Xilinx Software Command-Line Tool		Xilinx 的交互式、可脚本化命令行工具；使用 Tcl 命令控制开发板调试流程。本项目用它连接 JTAG、列出调试目标、初始化 PS、下载程序，以及读取 DDR。它运行在电脑上，不是芯片内部硬件。
JTAG芯片测试与调试接口标准。调试器通过它扫描芯片内部的一组 TAP。XSCT 连接板卡、枚举目标、下载 bitstream/ELF，或访问处理器调试资源。
TAP
Test Access Port		JTAG 链上的测试访问端口，带有状态机和数据寄存器；芯片可以包含多个 TAP/目标。PS TAP、PMU、PL 是 XSCT/JTAG 能看到的不同目标。能列出它们不代表 DDR 读写已经成功。
PS
Processing System		ZynqMP 芯片里的处理系统，含 ARM Cortex-A53、内存控制器、外设等。运行 standalone 软件并通过 DDR 控制器访问 PS DDR。
PS TAPPS 一侧的 JTAG 调试入口，连接到 PS 内部调试基础设施。经调试访问路径继续选中 A53 等目标，或尝试访问 PS 地址空间。它本身不是 A53 核，也不是 DDR。
DAP
Debug Access Port		ARM 调试架构中的调试访问端口，可提供一个或多个 Access Port。JTAG 调试器通过它访问处理器调试单元；具备相应 AP 时，也可访问系统存储器映射空间。
AXI APDAP 中的一类访问端口，通过 AXI 总线发起系统存储器映射读写。XSCT 读 PS DDR 时可能走此路径。AXI AP transaction error 表示该次总线访问失败，即便 JTAG 目标仍能枚举。
PMU
Platform Management Unit		ZynqMP 内负责平台管理工作的控制单元，包含专用的 MicroBlaze 处理器。XSCT 可能把 PMU 处理器作为独立调试目标显示。它和 A53、PL 是不同目标。
PL
Programmable Logic		芯片里的可编程逻辑，也就是 FPGA fabric。JTAG 可访问 PL 配置目标、下载 bitstream；这与经 PS DDR 传输大权重是不同用途。
PSUProcessing System Unit，ZynqMP 处理系统的器件/子系统标识；XSCT targets 列表中常用作 PS 管理目标名称。项目 Tcl 脚本以 name =~ "PSU" 选目标来执行初始化或 DDR 读取。具体可选 target 名称以当前 XSCT 枚举结果为准。
DDR sentinel从内存关键地址读取的少量已知数据，用作快速完整性检查。首尾 sentinel 一致可快速发现明显的未加载/错误地址问题；完整权重还需通过全量 CRC 等校验。

如何解读一次探测

如果 XSCT 能列出 PS TAP / PMU / PL，但读取 PS DDR 时报告 AXI AP transaction error，可以确认 JTAG 链路至少识别到了芯片；不能据此判断 DDR 内容正确，也不能把问题简单归因于 PC 网卡 IP。应继续检查 PS 初始化、电源/复位状态和 AXI AP 到 DDR 的访问是否恢复。
