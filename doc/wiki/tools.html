tools/ 里的脚本构成「模型 → golden → fixture → 上板」的完整通路； tests/ 冻结协议与数值口径；artifacts/ 保存被 Git 忽略的大体积中间产物。

从零到上板的调用顺序

脚本作用关键参数
tools/inspect_qwen_model.py读取 config 与 safetensors 头，打印结构与权重 shape--max-weights、--filter
tools/read_npy.py通用 .npy 查看器—
tools/export_lm_head_weight.py从 safetensors 直接导出 tied embedding 权重，不依赖 torch/safetensors 包输出固定校验 [151936, 896]、FP16
tools/prepare_lm_head_hls_fixture.py把 trace 转成 hidden.fp16.bin / history_bitmap.u32.bin / golden_logits.fp16.bin / expected_token.txt—
tools/run_module16_tcp_loopback.py本机 TCP 回环，用 NumPy 后端替代板端--step 0..7
tools/stage_h4_board_small_test.py4×4 受控上板用例，含 penalty 改变 Top-1 的构造无需完整权重
tools/run_module16_board_trace.py真实板卡 trace 客户端，默认不启用 penalty--host、--port、--step、--load-weight、--chunk-bytes、--return-logits、--enable-repetition-penalty、--inspect-only
tools/orin_qwen25_smoke.py在 Jetson Orin 上跑 Qwen2.5-0.5B-Instruct，建立异构基线--model-path、--prompt、--max-new-tokens
realFpga/tools/stage_f_board_smoke.py板端 LMH1 协议 smoke：分片帧头、CRC 错误恢复、多帧会话—
tests/test_lm_head_cpu_reference.py公式、prefill 末位、penalty、argmax tie-break、BF16 读取6 项
tests/test_module16_tcp_protocol.py帧收发、CRC 拒绝、分块上传、PING/READY与前者合计 10 项
fixture 与权重的 SHA-256 必须留档：260 MiB 权重经过网络与 DDR 后若输出错误， 第一件要做的事是确认输入文件本身没被替换或损坏，这只能靠事先记录的摘要。
不要把大文件提交进 Git：artifacts/ 已被忽略； 仓库内另有一个约 80 MB 的 FlightLLM bitstream，低于 GitHub 100 MB 硬限制但高于 50 MB 推荐值， 继续增大 trace 时建议引入 Git LFS。
