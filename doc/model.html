2. 模型结构与权重

在动手写任何 FPGA / HLS 代码之前，必须先搞清楚一件事：我们要实现的模型到底长什么样。本章介绍 Qwen/Qwen2.5-0.5B-Instruct 的架构、config 关键参数、权重文件组织方式，以及 FPGA 开发必须理解的几个算子概念（GQA、RMSNorm、RoPE、SwiGLU）。

2.1 Config 关键参数

config 里的每一个数字，最终都会变成 FPGA 上的循环边界、RAM 深度或位宽决策。下表列出了对硬件实现最重要的参数：

2.2 逻辑模块结构

整个模型就是一个 Qwen2ForCausalLM：一份 embedding 表、24 个结构完全相同的 decoder layer、一个最终 RMSNorm，再加一个 lm_head 输出投影。每个 decoder layer 内部包含 self-attention（GQA）和 SwiGLU MLP 两块，前后各有一个 RMSNorm。所有权重的名称和形状如下：

Qwen2ForCausalLM
├── model.embed_tokens.weight            [151936, 896]   # 词表 embedding
├── model.layers[0..23]                                      # 共 24 层，每层结构相同
│   ├── input_layernorm.weight             [896]           # 注意力前的 RMSNorm
│   ├── self_attn.q_proj.weight            [896, 896]      # Q 投影（14 头 × 64 维）
│   ├── self_attn.k_proj.weight            [128, 896]      # K 投影（2 头 × 64 维）
│   ├── self_attn.v_proj.weight            [128, 896]      # V 投影（2 头 × 64 维）
│   ├── self_attn.o_proj.weight            [896, 896]      # 注意力输出投影
│   ├── post_attention_layernorm.weight    [896]           # MLP 前的 RMSNorm
│   ├── mlp.gate_proj.weight               [4864, 896]     # SwiGLU gate
│   ├── mlp.up_proj.weight                 [4864, 896]     # SwiGLU up
│   └── mlp.down_proj.weight               [896, 4864]     # SwiGLU down
├── model.norm.weight                      [896]           # 最终 RMSNorm
└── lm_head.weight                         [151936, 896]   # 输出词表投影（逻辑名）

2.3 重点：tied lm_head（共享词表权重）

config 中 tie_word_embeddings=True，因此 model.safetensors 里没有单独的 lm_head.weight tensor —— lm_head 直接复用 model.embed_tokens.weight 作为输出词表投影权重。这对 FPGA 意味着：只需导出一份 151936×896 权重，embedding 查表和最后的 logits 投影共用同一份数据，板端存储和加载都可以省掉一半。

2.5 关键算子概念科普

FPGA 实现本质上是把下面这几个算子逐个搬到硬件上。先建立概念，后面的 trace 比对和 HLS 设计才有意义。

GQA（Grouped-Query Attention，分组查询注意力）

标准多头注意力里每个 Q 头都有自己的 K、V 头；GQA 则让多个 Q 头共享同一组 K、V 头。本模型有 14 个 Q 头，却只有 2 组 KV 头，每组 KV 被 7 个 Q 头复用（repeat 7 倍）。这就是为什么 q_proj 输出是 896 维（14×64），而 k_proj/v_proj 输出只有 128 维（2×64）。GQA 大幅减小了 KV cache 的体积，对存储带宽受限的 FPGA 尤其友好。

RMSNorm（均方根归一化）

LayerNorm 的简化版：不做均值平移，只用均方根对向量做缩放，再乘以一个可学习的逐元素权重。公式为 x / sqrt(mean(x²) + eps) * weight，本模型 eps = 1e-6。每一层有两个 RMSNorm（attention 前、MLP 前），外加最后一层一个最终 norm，权重都只有 896 维，非常适合在 FPGA 上用一个小向量乘法实现。

RoPE（Rotary Position Embedding，旋转位置编码）

不加位置向量，而是把 Q、K 向量的相邻两维看作一个二维平面，按位置序号做旋转，从而让注意力天然感知相对距离。旋转频率由基频 theta = 1000000.0 决定。硬件上通常预计算 sin/cos 表，再做逐对旋转。

SwiGLU MLP

本模型的前馈网络不是普通的「升维 → 激活 → 降维」，而是三投影结构：gate_proj 和 up_proj 各自把 896 维升到 4864 维，然后计算 silu(gate) * up，最后由 down_proj 降回 896 维。三个矩阵是模型内计算量的主力，也是逐层验证时最需要关注的模块。

2.6 FPGA 第 0 层 bring-up 常用权重清单

做第一层（layers.0）逐级点亮时，通常只需要下面这些权重。一共 13 项，先备齐再开始比对：

model.layers.0.input_layernorm.weight            # RMSNorm γ
model.layers.0.self_attn.q_proj.weight           # Q 投影权重
model.layers.0.self_attn.q_proj.bias             # Q 投影 bias（本模型 q/k/v 带 bias）
model.layers.0.self_attn.k_proj.weight           # K 投影权重
model.layers.0.self_attn.k_proj.bias             # K 投影 bias
model.layers.0.self_attn.v_proj.weight           # V 投影权重
model.layers.0.self_attn.v_proj.bias             # V 投影 bias
model.layers.0.self_attn.o_proj.weight           # 输出投影权重
model.layers.0.post_attention_layernorm.weight   # MLP 前 RMSNorm γ
model.layers.0.mlp.gate_proj.weight              # SwiGLU gate
model.layers.0.mlp.up_proj.weight                # SwiGLU up
model.layers.0.mlp.down_proj.weight              # SwiGLU down
model.norm.weight                                # 最终 RMSNorm γ
lm_head.weight                                   # 实际读取的是 model.embed_tokens.weight（tied）
注意最后一项：清单里写 lm_head.weight 只是为了表达逻辑用途，实际导出时必须从 model.embed_tokens.weight 读取（见 2.3 节），不要在 safetensors 里找不存在的 tensor。
