LMH1 网络协议

主机与板端之间只有一个协议：24 字节固定帧头 + 变长 payload，全部 little-endian。 板端实现位于 realFpga/vitis/workspace/lm_head_net_diag/src/lwip_lm_head_raw_server.c， 监听 TCP 19016。权重只在启动时上传一次，之后每个 token 只发一次 RUN_TOKEN。

flags 位宏含义
bit 0LMH_FLAG_ENABLE_PENALTY启用 repetition penalty
bit 1LMH_FLAG_WANT_LOGITS响应附带 151936 个 FP16 raw logits
bit 2LMH_FLAG_FIRST_CHUNK权重传输首块，要求 offset = 0
bit 3LMH_FLAG_LAST_CHUNK权重传输末块，末块结束位置必须等于 total_bytes

命令与载荷

opcode名称payload响应
1LMH_OPCODE_LOAD_WEIGHT total_bytes u64 · hidden_size u32 · vocab_size u32 · offset u64 · chunk_data（前缀 24 B） status
2LMH_OPCODE_RUN_TOKEN hidden_size u32 · vocab_size u32 · repetition_penalty f32 · history_words u32 + hidden[896] FP16 + history_bitmap[4748] u32（前缀 16 B） status u32 · selected_token u32 · selected_score f32 · logits_bytes u32，WANT_LOGITS 时追加 303872 B
3LMH_OPCODE_PING 无 hidden_size · vocab_size · weight_bytes
0xFFFFLMH_OPCODE_ERROR UTF-8 错误信息 —
历史坑（log 044）：错误响应曾因 header 与 payload 未全部被对端 ACK 就关闭连接而被截断。 修复方式是新增 tx_acked，由 sent_callback() 累计已确认字节数，确认发送干净后再关闭。
软件模拟器：上板前可先用 net/fpga_server_emulator.py + tools/run_module16_tcp_loopback.py 在 127.0.0.1 上跑通同一套帧格式（计算后端为 NumPy），协议与客户端代码零改动即可切换到真实板卡。
