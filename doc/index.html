1. 项目总览

LLM_FPGA 是一个面向 FPGA 大模型推理验证的 Qwen2.5-0.5B-Instruct 参考工程。它的目标不是搭建生产级推理服务，而是建立一个 correctness-first（正确性优先） 的开发闭环：

先用插桩版 PyTorch 导出模型每个模块的中间量（golden trace），再用 FPGA / C++ / HLS 实现相同模块，把每个模块的输出和 golden .npy 文件逐项比较，全部对齐后再谈性能优化。

仓库收集的三类内容

  1. Qwen2.5-0.5B-Instruct 完整 PyTorch golden trace —— 从 prompt 到 8 个生成 token 的全部中间张量（7386 个 .npy 文件）。
  2. Python 推理参考代码 —— 从 prompt 到输出 token 的完整推理流程，以及模块级数学参考实现（RMSNorm、RoPE、GQA、Attention、SwiGLU、lm_head）。
  3. FPGA 实现与部署 —— 模块 16（LM Head）的 Vitis HLS 内核、LMH1 TCP 协议、以及 AXU9EGB 真实板卡的完整 bring-up 工程；另附 FlightLLM demo 工程作为工程组织参考。

整体开发闭环

插桩版 Transformers（FP16 eager 推理）
        │  导出 7386 个 golden .npy
        ▼
qwen25_0p5b_instruct_full_generation_trace/   ← golden trace 数据集
        │  tools/prepare_lm_head_hls_fixture.py 压缩成紧凑 fixture
        ▼
artifacts/module16_hls_fixtures/              ← 每步 4 个文件（hidden/logits/history/token）
        │
        ├──► HLS C 仿真（csim）逐 bit 比对 ──► RTL 协同仿真（cosim）
        │
        └──► LMH1 TCP 协议 ──► AXU9EGB 真实板卡（100 MHz 验收 8/8 PASS）

当前进展一览

Golden Trace

8 步生成（1 prefill + 7 decode）× 24 层全量中间量已导出，prompt「你好，请用一句话介绍你自己。」，输出「我是Qwen，由阿里云开发」。

模块 16 HLS

LM Head（151936×896 FP16 矩阵乘 + repetition penalty + argmax）C 仿真 8/8 PASS，cosim PASS，已导出 HLS IP。

真实板卡验收

AXU9EGB（XCZU9EG）100 MHz 下 8 步 token 与 golden 完全一致，151936 维 logits 最大误差 0.015625（< 0.02 门限）。
